# 公开糖尿病数据导入

来源：Michael Kahn, Diabetes, UCI, https://doi.org/10.24432/C5T59G ，CC BY 4.0。
官方包：https://archive.ics.uci.edu/static/public/34/diabetes.zip 。
SHA256：dd5c95c4f125222d894a9478ee8d63983bc32581d53d79d02f1057ab1bcd39a9。

首批匿名受试者 01、02、03 分别使用独立患者账号，姓名明确标注公开数据集。
这是公开的历史记录，不是人工模拟、当前患者资料或 CGM 连续记录。
只导入代码 48、57–64 的血糖；胰岛素、饮食、运动和症状保留在原包中。
原日期不平移。原始时区未提供，按 UTC 容器保存原钟面时间，备注显式说明，
不得据此判断当地昼夜规律。部分纸质记录时间由原数据集按餐次指定。
超出系统 20–600 mg/dL 范围或格式无效的血糖行列入拒绝清单，不截断、不填补。
受试者和原始行号进入备注，稳定 UUID 防止重复导入。事务失败不留下部分结果。
账号使用随机丢弃密码，不创建登录会话、医护授权、推送设备或主动关怀授权。

在 api 环境下运行：
`python -m antang_api.import_public_diabetes --archive /path/uci-diabetes.zip`
默认仅预检；加 `--apply` 才写入当前明确配置的数据库。可用 `--subjects 01 02 03` 选择受试者。
写入前需备份并 `alembic upgrade head`，不能给普通患者写入接口开放来源自选。
看板需选择导入回执中的历史日期，自定义起止日期查看。

首批本地导入 881 条血糖（01:369、02:373、03:139），拒绝 7 条。看板自定义时间范围每次最多 90 天；超过范围需分段查看。线上尚待 SSH 维护通道恢复后部署与导入。
