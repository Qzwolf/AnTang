# 医院工作台预览调整
用户要求以医生查看血糖与治疗记录为中心整合，保持绿色主色，使用严肃、方正、紧凑的信息结构。
本地预览撤销20个仅含PDF摘要样本对审核医护的展示授权，保留报告和原始数据。默认列表仍为真实来源的数据集样本，未改变其他患者授权。
突出患者姓名、血糖关键指标、曲线和胰岛素/饮食时间轴；删除装饰性英文小字，列表隐藏冗长UUID。
无手环数据时隐藏整个空白区域；健康档案与数据来源改为默认折叠，明细表限制高度。
来源追溯在后端保留，不修改剂量单位或血糖原始数据，不对线上生产发布。

患者标题与列表名称使用冒号分隔，标题下隐藏冗长账号UUID；仅调整显示，不改数据库账号或研究受试者编号。

血糖采样点支持点击或Enter/空格选中，放大高亮并显示日期时间、数值、单位及来源。支持以选中点为中心放大附近两小时和恢复完整查询范围；仅缩放已有返回采样，不插值或改变原始数据。切换患者、日期或单位时重新渲染并清除旧选中状态。
